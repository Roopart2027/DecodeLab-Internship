# Random Password Generator

## Project Description

This project is a Random Password Generator developed using Python.

The program asks the user to enter the desired password length and generates a random password.

## Features

* User enters password length.
* Generates a random password.
* Uses letters, numbers, and special characters.
* Uses Python's `random` module.
* Uses Python's `string` module.
* Checks for invalid input.

## Technologies Used

* Python
* Random Module
* String Module

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:

`python password_generator.py`

4. Enter the password length.
5. The program will generate a random password.

## Example

Input:

`8`

Output:

`a#K9@mP2`
