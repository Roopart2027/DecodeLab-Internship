# Rule-Based AI Chatbot

## Project Overview

This is a Rule-Based AI Chatbot created using Python for the DecodeLabs AI Engineering Internship – Project 1 Week 1.

## Features

* Greeting messages
* Date and time
* Help command
* Chatbot identity
* Fallback response
* Exit command

## How to Run

Open the terminal and type:

python chatbot.py
