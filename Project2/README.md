# Data Classification Using AI

## Project Overview

This project is developed as part of the DecodeLabs AI Engineering Internship – Project 2, Week 2.

The project uses Machine Learning to classify flowers into different categories using the Iris dataset.

## Objective

The objective is to train an AI model using flower measurements and predict the type of a new flower.

## Dataset

The Iris dataset contains four features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The flowers are classified into:

* Setosa
* Versicolor
* Virginica

## Machine Learning Algorithm

Decision Tree Classifier is used for classification.

## Technologies Used

* Python
* Scikit-learn

## Machine Learning Process

1. Load the Iris dataset.
2. Separate input features and output labels.
3. Split the data into training and testing data.
4. Train the Decision Tree model.
5. Test the model.
6. Calculate accuracy.
7. Predict the class of a new flower.

## Result

The trained model successfully classifies Iris flowers and achieves high classification accuracy on the test data.

## How to Run

Open the terminal and run:

python classification.py
